# VanaNetra Backend

Production-style Express/MongoDB API for the VanaNetra forest monitoring frontend.

## Architecture
controllers -> routes -> middleware -> models -> MongoDB

## Run
1. Copy `.env.example` to `.env`.
2. `npm install`
3. `npm run seed`
4. `npm run dev`

Demo: admin@vananetra.local / Admin@123, official@vananetra.local / Admin@123, public@vananetra.local / Admin@123.
